## Process

UI findings came from three independent Opus reviewers (desktop, tablet/phone, keyboard/a11y/copy) driving Playwright at 1920–360px with the Bungie manifest loaded; their reports are summarized in the commit messages. Implementation was delegated to Sonnet (with Haiku helpers) in batches with disjoint file ownership; each batch was reviewed by an Opus subagent at medium effort, and the findings were fixed before committing. Every commit passes typecheck, tests, validate, format:check and the editor build.

## Partner bandwidth (measured, no change made)

`CharacterStatInfo-NI.json`: 35.7 KB raw, 8.1 KB gzip, 6.0 KB brotli (pretty file 101.7 KB / 9.9 KB gzip). Expanded 101-entry curves are ~36% of the raw NI file; 5 are constant and 18 linear, so collapsing them would save ~24% raw but little after gzip (GitHub Pages compresses), and partners would have to re-implement curve evaluation. A pre-evaluated companion export was prototyped in the plan and dropped: it would add more bytes than it saves partner compute. Recommendation: keep the format; point partners at the NI file and the new `.d.ts`.

## Open questions and deferred items

- Core validation messages now use editor labels ("Set Cooldown override, Cooldown scalar or
  Chunk energy scalar"); `npm run validate` users see the JSON path next to them but not the

  tested live after the merge, because `workflow_dispatch` needs `build-data.yml` on the default
  branch (master has only the Crowdin workflows). Unverified until then: branch protection on
  master, org approval for fine-grained tokens, exact GitHub error texts, and the `github-pages`
  environment rules. A retried PR save whose PR already exists is not handled specially.
